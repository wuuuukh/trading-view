# 過去模擬交易

## 角色定位

過去模擬交易是獨立回測模組，不是 Agent，也不和現有 scan、paper trade、Dashboard 資料合併。

目的：從指定日期開始，每個交易日照當時可見資料跑策略，模擬資金、持股、交易紀錄與最後獲利。

## 預設設定

```text
start_date: 2026-01-01
end_date: 2026-05-31
initial_capital: 10000
output_scope: independent
```

## 目前可做

- 使用個股日 K 做日線級歷史模擬。
- 每天只使用當日以前資料，避免偷看未來。
- 用既有 `RuleConstrainedAgent` / Candidate Scanner 產生每日股票判斷。
- 模擬現金、持股、市值、已實現損益、未實現損益、總資產。
- 輸出獨立 JSON / CSV / Markdown。

## 資料待補

- 加權指數歷史日 K：若未提供，暫時標記 `index_data_missing`。
- 5K / 15K / 60K：未提供前，不做完整盤中切入回測。
- VWAP：未提供前，不做 VWAP 條件。
- 正式籌碼資料：未提供前，只能使用現有 proxy 或標記缺資料。
- 法人資料：未提供前標記 `institution_data_missing`。

## 模擬規則草稿

每日流程：

```text
1. 讀取當日以前的個股日 K
2. 跑 Candidate Scanner
3. 依 final action 模擬交易
4. 更新現金與持股
5. 記錄每日資產曲線
6. 到結束日統計績效
```

第一版保守執行規則：

- `accept`：若沒有持股，用可用現金的 1/3 建倉。
- `hold`：已有持股則續抱；沒有持股則不買。
- `reject`：已有持股則先不強制賣出，除非後續風控規則補上。
- 盤中資料不足時，不做盤中切入判斷。

## 輸出檔案

```text
reports/historical_simulation_2026-01-01_to_2026-05-31.json
reports/historical_simulation_2026-01-01_to_2026-05-31.csv
reports/historical_simulation_2026-01-01_to_2026-05-31.md
```

## 績效欄位

- 初始本金
- 期末資產
- 總報酬
- 已實現損益
- 未實現損益
- 交易次數
- 勝率
- 最大回撤
- 每日資產曲線
- 每筆交易紀錄

## 禁止事項

- 不使用未來資料。
- 不把日線模擬說成完整盤中切入回測。
- 不和現有 paper trade 紀錄混在一起。
- 不自動改既有 Dashboard，除非使用者要求。
