用途

這是一套圍繞個人交易 SOP、操作思維、均線系統、型態邏輯與籌碼面選股規則所設計的 rule-constrained AI Agent Trading 系統。

原始交易 SOP

只做強勢
  • 只做強勢股，不做弱勢股。
  • 只做順勢，不抄底，不摸頂。
  • 先看結構，再看均線，再看量價，最後才是進場。
技術規則
  • 固定均線：3、8、21、55、144、233。
  • 型態先支援 W 型、突破型、N 字型。
  • 沒有結構，不做；沒有量，不做；沒有趨勢，不做；沒有規則，不做。
籌碼規則
  • 加入大股東每週持股張數變化。
  • 籌碼門檻：400 / 600 / 800 / 1000 張。
  • 前 30 名大股東持股同步增加則額外加分。
  • 籌碼面是加分與排序條件，不單獨取代技術結構。

Rule-Constrained AI Agent 執行規則

允許切入前置條件
  • 大盤允許；加權指數跌幅超過 3% 則轉保守。
  • 只做主流題材、強勢族群、攻擊量與籌碼偏多股票。
  • 型態先成立：突破、W、N、平台整理轉強或均線開花。
  • 日K、週K、月K均線共振，月K 3MA 未跌破。
  • 60K MACD 綠柱縮短或紅柱翻揚。
現價切入點
  • 開盤連三根 5K 紅K，高低點墊高且量能不衰退。
  • 5K 爆大量後不追高，等回撤日K 3MA 不破。
  • 開盤連三黑但日K結構未破，回測日K 3MA 不破。
  • 以上切入點需配合 60K MACD 動能轉強。
  • 短線看日K 3MA / 8MA，中長線看週K與月K 3MA。
每週日選股更新
  • 每週日更新一次選股池，分為實際操作組與觀察組。
  • 實際操作組保留獲利為正、結構未破、月K 3MA 未跌破。
  • 獲利轉負、結構轉弱、均線破壞、主流退潮則降級。
  • 降級股票放觀察組 1 週，未轉強自動淘汰。
  • 跌破月K 3MA、空頭排列、爆量長黑或籌碼鬆動直接淘汰。
