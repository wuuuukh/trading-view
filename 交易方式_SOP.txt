Rule-Constrained AI Agent Trading System SOP

一、核心原則

1. 尊重大盤
- 加權指數若跌幅超過 3%，整體操作轉保守。
- 不主動攻擊。
- 降低新倉。
- 不追價。

2. 只做強勢股
只關注：
- 主流題材。
- 強勢族群。
- 有攻擊量股票。
- 法人偏多。
- 籌碼偏多。
- 多頭均線排列股票。

不做：
- 弱勢股。
- 空頭股。
- 跌破重要均線股票。
- 無量股票。

3. 多週期共振
同時檢查：
- 日K。
- 週K。
- 月K。

只有均線開花共振才可列入操作。

二、均線系統

固定均線：
- 3MA。
- 8MA。
- 21MA。
- 55MA。
- 144MA。
- 233MA。

三、均線開花定義

1. 日線開花
- 3MA > 8MA > 21MA。
- 均線斜率向上。
- 股價站上短均。

2. 週線開花
- 週K均線同步向上。
- 週K趨勢延續。

3. 月線開花
- 月線趨勢向上。
- 股價不破月K 3MA。

四、型態條件

型態是先決條件，不是單獨進場依據。

可觀察型態：
- 突破型態。
- W型態。
- N字型態。
- 平台整理後轉強。
- 均線開花型態。

型態必須同時配合：
- 均線。
- 量能。
- 籌碼。
- 大盤。

五、籌碼條件

檢查：
- 大股東持股增加。
- 前30名股東同步增加。
- 法人買超。
- 投信偏多。
- 主力籌碼集中。

週頻資料優先。

六、進場切入點

1. 切入點1：開盤八法紅紅紅

條件：
- 連續三根5K紅K。
- 高點墊高。
- 低點墊高。
- 量能不能明顯衰退。

動作：
- 第三根5K直接現價買進。

2. 切入點2：5K爆大量後回撤3MA

條件：
- 單根5K爆大量。
- 量 > 近一週所有5K均量2倍以上。

動作：
- 不追高。
- 等回撤日K 3MA。
- 不破再現價買入。

3. 切入點3：開盤連三黑後回測3MA

條件：
- 開盤連續三根5K黑K。
- 日K結構未破壞。
- 日K 3MA未跌破。

動作：
- 等回測日K 3MA不破。
- 現價買入。

4. 切入點4：60K MACD確認

條件：
- 60K MACD綠柱縮短，或
- 60K MACD紅柱翻揚。

動作：
- 配合上述三種切入點。
- 確認動能轉強後現價買入。

七、持股規則

1. 短線持股
- 觀察日K 3MA。
- 觀察日K 8MA。

2. 中線持股
- 觀察週K均線排列。
- 觀察週K趨勢延續。

3. 長線持股
- 核心為月K 3MA。
- 不破月K 3MA可續抱。
- 月K結構破壞再減碼或出場。

八、AI Agent 判斷流程

依序執行：

1. 檢查大盤。
2. 檢查是否為強勢股。
3. 檢查型態是否成立。
4. 檢查日/週/月均線是否共振。
5. 檢查籌碼是否偏多。
6. 檢查60K MACD是否轉強。
7. 檢查5K開盤節奏。
8. 最後才允許現價切入。

九、選股更新機制

每週更新一次選股池。

分成兩組：
- 實際操作組。
- 觀察組。

1. 實際操作組

保留條件：
- 保留目前獲利為正值股票。
- 保留結構未破壞股票。
- 保留月K 3MA未跌破股票。

移出條件：
- 獲利轉負。
- 結構轉弱。
- 均線破壞。
- 主流退潮。

2. 觀察組

用途：
- 放置新觀察股票。
- 放置從操作組降級股票。

規則：
- 被替換股票先保留在觀察組1週。
- 若1週後仍未轉強，或結構持續惡化，自動淘汰。

3. 自動淘汰條件

以下任一成立則淘汰：
- 跌破月K 3MA。
- 均線空頭排列。
- 爆量長黑破壞結構。
- 量縮無趨勢。
- 主流族群退潮。
- 法人連續偏空。
- 籌碼鬆動。

十、核心策略總結

大盤允許時，只做強勢股。

先看型態，再看開盤節奏。

配合：
- 60K MACD。
- 日K 3MA / 8MA。
- 日/週/月均線共振。
- 籌碼集中。

確認後現價切入。

月K 3MA不破則長期持有。
